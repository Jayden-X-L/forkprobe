社区选择信号

真实选择积累到足够样本后，再公开结果。

ForkProbe 可在你选定 Winner 并继续任务时，匿名分享任务类型、参选 Skill 名称和最终选择。每个任务类型达到公开阈值后，社区才能看到聚合胜率。

数据流程

一次选择，四个清晰步骤。

1

本地比较

任务内容、生成结果和文件继续保留在你的设备上。

2

选择 Winner

Report 在继续按钮旁展示匿名分享选项，首次使用默认勾选，你可以取消。

3

最小事件

仅发送任务类型、参选 Skill 名称和最终选择。

4

聚合公开

同一任务类型至少累计 20 次有效选择后，才展示 Skill 和两两胜率。

隐私边界

公开说明收集什么，也说明不收集什么。

写入 D1匿名事件 ID、任务类型、参选 Skill 名称、最终选择。
不写入 D1任务原文、模型输出、生成文件、文件路径、用户名、邮箱和账号标识。
网络与限流请求经过 Cloudflare Worker；网络来源仅用于边缘限流，不作为选择事件字段写入 D1。
用户控制你可以在 Report 继续步骤取消匿名分享，也可以通过 FORKPROBE_TELEMETRY=0 全局关闭。
公开方式只发布达到阈值后的聚合统计，不公开单条事件或个人选择。
当前按任务场景统计，不按行业统计。 现有匿名事件没有行业字段。办公、科研、金融等行业维度只有在未来明确新增、公开说明并再次评估隐私边界后才会使用。
